## Enable once (repo Settings)

1. Open [Pages settings](https://github.com/bigmustachegame/thepill/settings/pages)
2. **Source:** Deploy from a branch
3. **Branch:** `main` → `/docs`
4. Save — pages go live in ~1 minute
